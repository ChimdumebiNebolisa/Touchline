# Touchline Private Playtest Script

Use this script for your first session. Take notes as you go; fill in [feedback_form.md](feedback_form.md) at the end.

**Suggested role for first run:** Manager (broadest authority).  
**Optional second run:** Assistant Manager or Head Coach to compare role differences.

---

## Before you start

- [ ] Read [private_playtest_readme.md](private_playtest_readme.md)
- [ ] Skim [known_limitations.md](known_limitations.md) so you know what is intentionally shallow
- [ ] Set window to at least **1280×720**
- [ ] Allow **60–90 minutes** uninterrupted

---

## Session flow (all roles)

### 1. Start a new career

- From the main menu, choose **New Career** (not Continue).
- Note whether the slot preview on the main menu is readable before you start.

### 2. Pick a role

Choose one:

- **Assistant Manager** — recommendation/suggestion authority
- **Head Coach** — football-side control, limited recruitment
- **Manager** — broad project control within board limits

Write down which you picked.

### 3. Pick a background

- Select any background on the Career Setup screen.
- Note whether the preview panel explains how background affects your start.

### 4. Pick a license

- Select a license tier.
- Note whether license limits feel explained (scouting depth, staff trust, etc.).

### 5. Pick a club

- Read the club shortlist and preview panel.
- Select a club and confirm.
- Note: identity, board line, opening fixture, and pressure tags.

### 6. Read the dashboard

On the club dashboard, look for:

- Next best action / next decision
- Morale, pressure, or authority context
- Training/scouting section
- Recruitment/contracts section
- Job market or career section (Manager especially)

**Question:** Can you explain in one sentence what you should do this week?

### 7. Open squad

- Navigate to **Squad** via the sidebar.
- Check Starting XI vs non-starters.
- Look for **Profile Confidence** and partial-information cues on the squad panel.

### 8. Open a player profile

- Open at least one player profile from the squad screen.
- Find: **Known**, **Estimated**, **Unknown** blocks.
- Note scouting/license/staff explanation text.

**Question:** Do you trust what the game shows vs hides?

### 9. Open tactics

- Go to **Tactics**.
- Confirm the sidebar highlights **Tactics** (not Matchday).

### 10. Adjust or inspect tactics

- Change formation, press, tempo, width, or risk — or just read the preview.
- Save if your role allows direct saves (Head Coach / Manager).
- Note role-specific button labels (recommend vs save).

### 11. Check training/scouting

- Return to the dashboard.
- Use the training/scouting buttons in the insight card.
- Note whether actions match your role (recommend vs request vs direct assignment).

### 12. Advance time

- Find how to advance the week or reach the next matchday (dashboard actions, fixtures, or matchday flow).
- Note any news, events, or pressure changes after advancing.

### 13. Play Instant Sim

- Go to **Matchday**.
- Run **Instant Result** for the current fixture.
- Do **not** expect playable football controls — this is management simulation.

### 14. Review post-match

- Read scoreline, key stats, tactical causes, consequences, and next action.
- Check for clipped or empty layout areas.

**Question:** Does the post-match screen explain *why* the result happened?

### 15. Inspect Live Match or timed playback

- Return to matchday for a **different fixture** (or reload and replay).
- Choose **Watch Live Match** instead of instant result.
- Watch at least kickoff → mid-match → full time.
- Continue to post-match if prompted.

**Note:** Live match is **tactical playback**, not player-controlled football.

### 16. Check recruitment/contracts/job market

- On the dashboard, open recruitment/contracts and job-market sections.
- Note: these are **foundation-depth dashboard sections**, not full standalone screens.

**Question:** Does the UI honestly signal what you can and cannot do?

### 17. Save and reload

- Save from the dashboard or save/load flow.
- Return to main menu.
- Use **Continue Career** or **Load Game**.
- Confirm club, date, matchday, squad, and tactics survived reload.

### 18. Continue one more week

- Advance through at least one more matchday cycle (instant or live).
- Check fixtures and standings update sensibly.

### 19. Write feedback

- Complete [feedback_form.md](feedback_form.md)
- File bugs with [bug_report_template.md](bug_report_template.md) if needed

## Role-specific questions

Answer these **in addition** to the feedback form, for the role you played.

### Assistant Manager

1. Did buttons say **Recommend** or **Suggest** rather than direct action?
2. When you changed tactics, did the game feel like you were advising rather than deciding?
3. Did training/scouting feel appropriately limited?
4. After a bad result, did pressure feel lower than you expect for a Manager?
5. Would you want to play a full season as Assistant Manager, or did authority feel too thin?

### Head Coach

1. Could you **save tactics** and see them persist?
2. Did recruitment/contracts feel gated or request-based compared to Manager?
3. Did squad and matchday decisions feel like "your" football domain?
4. Was anything confusing about what Head Coach cannot do?
5. Did the role feel meaningfully different from Assistant Manager?

### Manager

1. Did dashboard actions feel direct (assign scouting, review contracts, open job market)?
2. Did recruitment/contracts/job-market sections feel powerful but still foundation-level?
3. Did partial player information plus scouting actions feel coherent for transfer planning?
4. Did board/fan/media pressure feel connected to results?
5. Did anything feel like it promised a full system but delivered a dashboard stub?
